# SQL Daily Practice

This folder contains my daily SQL exercises and solutions.

## Objectives

- Strengthen SQL fundamentals.
- Improve analytical thinking.
- Practice writing efficient queries.
- Develop skills for data analyst roles.

## Daily Exercise Structure

Each day's folder will contain:

- `solution.sql` — SQL solution query.
- `README.md` — Problem statement, explanation, and key learnings.
- Table creation scripts or sample data when required.

## Topics

- SELECT and filtering
- GROUP BY and aggregate functions
- JOINs
- Subqueries and CTEs
- Window functions
- CASE expressions
- Date and string functions

## Database

Microsoft SQL Server.

## Practice Approach

Each query will be tested before being uploaded to GitHub.
